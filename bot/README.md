# Telegram adapters placeholder

В MVP предусмотрен aiogram 3.x через входной webhook FastAPI, сохранение update и обработку в фоне.
Bot API не читает произвольную историю личных переписок пользователя. Клиентский MTProto — отдельный PoC.
Действующие Telegram API-токены и `.session` файлы в Git не помещать.
